# SE Labo

SE Laboは、システムズエンジニアリング（SE）のアイデアを試すためのリポジトリです。

SEとは、複雑な製品やサービスを「誰のために、何を実現し、どう確かめるか」という流れで考える方法です。機械、ソフトウェア、人の作業、運用ルールなどをまとめて扱います。

このリポジトリでは、完成した標準や正解を公開するのではありません。試したい考え方、実行方法、結果の確認方法を、実験として公開します。

## 読み始める場所

1. 上の表から、興味のある実験を選びます。
2. 各実験のREADMEで、目的と使い方を確認します。
3. 用途別ガイドから、自分の目的に近い方法を選びます。
4. 実行結果を、40点Gateと人のレビューで評価します。

実験の共通ルールは、[experiments/README.md](experiments/README.md)にまとめています。

3製品でのQ&A評価実行は、[evaluation_runs/2026-08-21](evaluation_runs/2026-08-21/README.md)に記録しています。

## 大切にすること

- AIが推測した内容と、人が確認した事実を分けます。
- 実際には行っていない試験を「実施済み」と書きません。
- 何を入力し、どの設定で実行したかを記録します。
- うまくいった例だけでなく、失敗や限界も残します。
- 安全、法律、認証、契約、設計承認は、専門家と責任者が判断します。
- AIの自己評価だけで合格にせず、必要に応じて独立した評価を行います。
- 実験側で候補数を勝手に打ち切らず、実行環境の上限と人工的な制限を区別します。
