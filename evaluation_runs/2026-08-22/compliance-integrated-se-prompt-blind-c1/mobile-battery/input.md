# ブラインドC1入力：モバイルバッテリー

このファイルは2026-08-21実験の合成Q&Aだけを抜き出した。B0独立Review Finding、C1-remediatedモデルおよびその評価結果は入力に含めない。

|質問|シミュレーション回答|残る不確実性|
|---|---|---|
|Q1. 主な目的は何か。|外出先や停電時に、スマートフォンなどの携帯機器へ必要な電力を供給すること。|対象機器、必要回数、利用時間|
|Q2. 主な利用者は誰か。|通勤・出張する成人、旅行者、家庭で非常用に保管する利用者。|子ども、介助者、業務用途|
|Q3. どの環境で使うか。|バッグ内、屋内外、移動中。高温の車内や航空機内など輸送条件は別途確認する。|温湿度、衝撃、輸送市場、航空規則|
|Q4. 何を重視するか。|安全な充電、残量の分かりやすさ、接続の確実さ、携帯性の順に重視する。|容量と重量、出力と発熱のトレードオフ|
|Q5. 既知の制約は何か。|USB-Cを主な接続候補とし、接続した機器へ過大な電力を供給しないこと。|USB規格、ポート数、急速充電方式|
|Q6. まだ決まっていないことは何か。|容量、出力、同時充電、残量表示、充電完了判定、航空輸送条件、電池寿命は未決定。|性能値、認証、電池化学系、廃棄方法|
