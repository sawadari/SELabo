# 最小実行入力例

次の例は、特定の法令・規格への適合性を主張しない、Schemaとプロンプトの動作確認用入力です。

```text
対象システム：充電式の携帯照明器具
目的：停電時に利用者が屋内の移動経路を照らせるようにする
対象市場：日本（候補。未確認）
製品分類：家庭用電気製品の可能性があるが未確認
意図する使用：成人が屋内で一時的に使用する
ライフサイクル：企画・開発
対象構成：照明本体、内蔵蓄電池、充電用インターフェース

法規・規格・認証情報：まだ正式原典を提供していない。適用候補の種類と、適用性判断に必要な調査項目だけを作成すること。正式名称、版、条項、引用文を推測しないこと。
```

期待する挙動は次のとおりです。

- 未取得のSourceを正式原典として記録しない。
- ApplicabilityAssessmentを`uncertain`にする。
- 市場、製品分類、電池、充電、表示、廃棄などについて、必要な調査を人の確認バックログへ送る。
- 法規由来と断定したRequirementや実在しないEvidenceItemを作らない。
- 一般的な安全候補を作る場合、由来を`ai_generic_seed`として法的Obligationと区別する。
