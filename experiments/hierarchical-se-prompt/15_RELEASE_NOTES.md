# リリースノート

## 1.0.0 — 最初の公開版

公開日：2026-08-21

この版は、GitHubで公開する最初の実験版です。以前の内部版番号は引き継がず、`1.0.0`から始めます。

## 含まれるもの

- 実行用のコアプロンプト
- 標準設定と用途別の設定例
- 生成するファイルを決める出力ルール
- SEモデルと要求文の検査ルール
- 中心となるSEモデルJSONのSchema
- 日本語の命名と文章のルール
- ルールと参考資料の対応表
- 用途別の使い方
- 配布方法と、ChatGPT Appにする場合の案

## この版で大切にしたこと

- AIの推測と、人が確認した情報を分ける。
- L0～L7を国際規格の固定階層として扱わない。
- 利害関係者のニーズと、システムへの要求を分ける。
- `10_se_model.json`を中心データとして扱う。
- SysMLの標準要素と、この実験独自の拡張候補を分ける。
- 実施していない試験やファイル生成を、実施済みと書かない。
- 要求が必須、禁止、推奨などのどれかを、`normative_level`で明記する。

## 今後の版番号

- 互換性を壊す大きな変更：メジャー版を上げる。
- 互換性を保った機能追加：マイナー版を上げる。
- 意味を変えない修正：パッチ版を上げる。

実験結果には、使用した版、AIモデル、設定、実行日時を記録します。
