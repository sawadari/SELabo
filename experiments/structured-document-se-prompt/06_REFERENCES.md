# 参考資料と設計判断

本実験は、リポジトリ内の実験1と、ユーザーが提供した「AI自動生成向け企画書・要件定義書の汎用構造化スキーマ調査」を直接の設計根拠とします。

| 参照 | 反映した内容 |
|---|---|
| `../hierarchical-se-prompt/README.md` | L0～L7、候補正本、40点初稿、人の確認 |
| `../hierarchical-se-prompt/schemas/se_model.schema.json` | 既存要素、状態軸、要求・検証・関係の基礎 |
| 添付調査 | planning、画面、API、データ、受入条件、document_views、未指定値保持 |
| OpenAPI / AsyncAPIの調査記載 | API契約の詳細を外部ネイティブ仕様へ委譲 |
| JSON Schema Draft 2020-12の調査記載 | 実験1Schemaとの合成検証 |

この実験では、添付調査に記載された外部基準の現行版適合を新たに検証していません。外部仕様・基準の正式な版、適用性、契約承認は人または権限ある担当者が確認します。
