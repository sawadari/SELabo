# VSE「40点Gate」とStop Rule

## 1. 定義
40点は100点満点の品質スコアではなく、*reviewable* の目標を示す。市場需要や戦略的優位性が実証されたことを意味しない。

| 状態 | 意味 |
|---|---|
| `below_reviewable` | 重要な問題・仮説・代替案・反証方法をレビューできない |
| `reviewable_40_candidate` | 不確実性の所在と次の判断を議論できる候補 |
| `overspecified_beyond_40` | 根拠不足のROI、需要、価格、因果効果、採用決定を確定している |
| `not_assessed` | Gate未実施。合格を主張しない |

## 2. 評価の5軸
1. **Objective / Scope**：目的、何を変えたいか、対象境界がある。
2. **Customer / Problem**：主要な顧客・購買関係者と問題仮説を説明できる。
3. **Hypothesis / Evidence**：推測と出典・観測を分け、主要仮説に反証条件がある。
4. **Alternatives / Decision**：同一問題について現状維持を含む比較、判断基準、決定者候補がある。
5. **Test / Next Action**：最も重大な不確実性を確認する次の行動・観測・人の担当がある。

軸別状態は`sufficient` / `weak` / `missing` / `over_specified` / `not_applicable`。同じ入力から複数の評価者が比較可能なよう、具体的なIDと根拠を書く。

## 3. Hard Blocker
- 重要5軸のいずれかが`missing`かつ確認方法すらない。
- 出典なしの数値（市場規模、売上、ROI、改善率、価格、受注確率等）を確定主張する。
- AI仮説/仮想顧客/架空実験を、実顧客・実測・承認済み決定とみなす。
- 未管理の重大な矛盾、存在しないID、誤った因果断定、機密の公開等がある。
- 意思決定に不可欠な現状維持・代替案を理由なしに除外する。
- 法務・契約・プライバシー・安全上の重大判断をAIが単独で確定する。

## 4. 初期指標（研究仮説値、合否を数値だけで決めない）
| 指標 | 仮の目安 | 補足 |
|---|---:|---|
| 主要要素のorigin/claim_stateの明示 | 100% | 自動検査可能 |
| 主要仮説の反証条件 | 100% | 内容の有効性は人が確認 |
| 主要戦略代替案の比較対象共通化 | 100% | 代替案が意味上比較可能かは人が確認 |
| 主要仮説から検証候補への接続 | 80%以上 | 定義した母数も記録 |
| 未管理の高・重大Finding | 0件 | 対応候補または差戻しを要する |

## 5. Stop Rule
上記5軸の主要事項と不確実性がレビュー可能になった時点で止める。必要以上のフレームワーク、広告文案、価格、予算詳細を生成しない。先へ進むには人の指示が必要。

## 6. 二層品質
`linguistic_quality`（明確な日本語、主語、比較条件、出典の書き方）と`semantic_validity`（情報・因果・戦略の妥当性）を分離する。前者の合格は後者の保証にならない。採否決定は権限者が行う。
