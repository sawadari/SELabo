# 4ラウンドの批判と設計変更履歴（**模擬レビュー**）

## 注意：評価の性格
以下は、前段会話で実施した**文献に基づく役割別の模擬批判**を設計判断へ転記したもの。実在のマーケティング専門家・営業専門家・実顧客・SE専門家へのヒアリング結果ではない。独立LLMモデルでのJ3レビューや実顧客による妥当性確認も未実施。

## R1：概念と対象境界
- Marketing：階層の完成が市場理解を意味しない。市場・顧客・競合は相互依存。
- Sales：利用者の賛同と、予算責任者の購買判断は別。
- Virtual Customer：問題の存在が購入意思の証拠にならない。
- SE：Need/Requirementを顧客の選択へ単純置換してはならない。
- **更新：** V0～V7を独立視点に変更し、Problem/Value/Hypothesis/Decision/Outcomeを別要素型とした。

## R2：戦略の実質
- Marketing：競合、資源配分、非選択、現状維持がない施策集は戦略にならない。
- Sales：需要が存在しても自社が獲得できるとは限らない。
- Virtual Customer：内製/他社/現状維持と比較できない価値提案を信頼しない。
- SE：トレーサビリティと因果性は別。
- **更新：** Alternative比較とStatus Quoを標準化し、因果関係型を独立させる。

## R3：運用負担と信頼
- Marketing：全データの人手閲覧は負担。
- Sales：商談中に複雑なフォームへ入力しない。機密管理が重要。
- Virtual Customer：数値根拠のないROIは信用できない。
- SE：JSONが整っていても入力が誤っていれば無意味。
- **更新：** 会話中心、正本JSONと投影の分離、機密の最小化、検査レイヤー分離。

## R4：研究としての妥当性
- Marketing：詳しい文章＝戦略成果ではない。
- Sales：商談率の前後変化がAIの因果効果とは限らない。
- Virtual Customer：模擬顧客の購買意思は市場実証ではない。
- SE：GateそのものにもFalse Passがあり得る。
- **更新：** B0/B1/B2/B3比較、独立Reviewer、実在専門家校正、実市場の検証を別の評価段階にした。
